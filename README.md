#Dataset and reference

## Project Overview
This project analyzes healthcare insurance claims data to identify cost drivers and financial leakage.
The dashboard is designed for executive decision-making and answers the question:
**"Where is the money going?"**

## Business Problem
The insurance company is experiencing financial losses and lacks visibility into:
- Costly claim types
- High-cost medical procedures and diagnoses
- Members driving the highest healthcare spend
- Differences between billed and paid amounts

## Tools Used
- Power BI (Data Cleaning, Modeling, Visualization)
- Power Query
- Excel (Dataset)
- GitHub (Project versioning)

## Key Analyses
- Claim Type Cost Breakdown
- CPT & ICD Cost Drivers
- High-Cost Member Analysis
- Billed vs Paid Ratio Analysis
